## 🏆 Top 3

### 1. Claude Code 2.1.312 fixes skills lookup and large CLAUDE.md overwrites

The release adds an oidc.user\_id\_claim option to the Claude apps gateway and click to send for queued messages in fullscreen. Fixes include Claude overwriting a very large CLAUDE.md, rules file or @-included file after seeing only its start (Write now asks it to read it all or edit in place), and per-directory and paths: skills not being found after a Bash cd deeper into a git repository.

**Why it matters to you:** Skills with paths: and big CLAUDE.md files are exactly how this repo is set up, so both fixes touch your daily workflow.

[Claude Code releases](https://github.com/anthropics/claude-code/releases/tag/v2.1.312)

### 2. Latent Space talks to Anthropic about the 'brain and hands' Managed Agents design

The episode covers how an agent's sandbox can die without taking the whole agent with it, the idea behind 'the brain and the hands', Anthropic's architecture for Claude Managed Agents. It features Katelyn Lesse and Angela Jiang.

**Why it matters to you:** A first-party-adjacent look at a harness design, which sits at the top of your list for agentic coding practice.

[Latent Space (YouTube)](https://www.youtube.com/watch?v=MRQTlwcW-aQ)

### 3. Study maps the hidden instruction stacks that coding agents send to models

Coding agents send models more than the user's prompt: added instructions, tool definitions and environmental context form an instruction stack. The paper says this stack steers execution and changes across releases, yet is largely unexposed to users and insufficiently characterized.

**Why it matters to you:** Context management and harness behaviour are your top topics, and this is an empirical look at what actually reaches the model.

[arXiv](https://arxiv.org/abs/2610.37332)
