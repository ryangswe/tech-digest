## 🏆 Top 3

### 1. Claude Code 2.1.314 adds write blocking and idle compaction

Adds permissions.blockWritesOutsideWorkingDirectories, so Write, Edit and NotebookEdit refuse paths outside the working directories in every permission mode. Idle compaction arrives in VS Code and Claude Desktop's Code tab: a conversation of 200K+ tokens left idle is summarized, and the summary is used on your next message if the prompt cache has expired. Also adds gateway group routing and fixes several failures.

**Why it matters to you:** Context compaction and permission behaviour are at the top of your Claude Code list, and the write-blocking setting touches how safely scheduled runs can be scoped.

[Claude Code releases](https://github.com/anthropics/claude-code/releases/tag/v2.1.314)

### 2. How Anthropic ships Claude with Claude: separating the brain from the hands

A Latent Space episode with Katelyn Lesse and Angela Jiang on Opus 5.5, the Claude Platform, and the engineering behind AI agents.

**Why it matters to you:** Agent harness design from the people building the platform fits your first and second interests.

[Latent Space](https://latent.space/p/opus55/)

### 3. OpenAI adds API credits for eligible ChatGPT subscriptions

Simon Willison notes that earlier this month Anthropic announced a benefit for its Max and Team subscriptions: $100, $200 and $500 per month subscribers get an equivalent amount of expiring API credits. OpenAI now has a similar benefit for eligible ChatGPT subscriptions.

**Why it matters to you:** A pricing move that touches the Anthropic API credits you may already be entitled to, which is on your model pricing list.

[Simon Willison](https://simonwillison.net/2026/Oct/29/api-credits/)
