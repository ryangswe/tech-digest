## 🏆 Top 3

### 1. Claude Code 2.1.311 fixes a pile of subagent, hook and compaction bugs

The release fixes long startup freezes when a CLAUDE.md holds a very long list item, subagents unable to use MCP tools from servers that finish connecting late, and stale MEMORY.md and CLAUDE.md content right after automatic compaction. SubagentStop hooks no longer run about twice a minute per running subagent. Standard-context sessions that run over 200K tokens now compact and continue instead of stopping with a usage-credits error.

**Why it matters to you:** Subagents, hooks, compaction and CLAUDE.md behaviour are the top of your list, and this release touches all four.

[Claude Code releases](https://github.com/anthropics/claude-code/releases/tag/v2.1.311)

### 2. Study asks why agents survive deleting old trajectory turns, and what it costs

Software engineering agents resend their whole trajectory to the model every turn, which motivates trimming it. Earlier work showed randomly deleting 75% of tokens in old turns may preserve agent effectiveness. This paper asks why, how agents compensate for the missing content, and what the hidden costs are.

**Why it matters to you:** Context-management techniques with evidence are on your want list, and this one examines what trimming costs an agent.

[arXiv](https://arxiv.org/abs/2610.35496)

### 3. Simple LLM harnesses outdiagnose hand-crafted root cause analysis agents

Many LLM agents for root cause analysis of microservice failures use hand-crafted investigation: standard operating procedures, fixed stages and role agents. Each is evaluated on its own data against few baselines, so it is unknown whether the design beats giving a model free rein. The paper's title reports that simple harnesses win.

**Why it matters to you:** A result on harness design with a comparison against baselines, which is the kind of evidence you asked for on what works in agent setups.

[arXiv](https://arxiv.org/abs/2610.35767)
