# What I want in my digest

Written as examples. The daily run ranks against this file; the weekly run proposes edits to it
as a PR, from your 👍/👎 ticks and comments. Edit freely. Order matters: earlier topics win ties.

**Reader:** a solo developer who ships with Claude Code daily, builds browser extensions and
in-browser ML tools, and makes community tools for trading card games.

## 1. Claude Code and agentic coding practice (highest priority)

Want:
- A Claude Code release that changes how subagents, skills, hooks, plugins, scheduled tasks or
  context compaction behave, with what changed in practice.
- A write-up of a harness design that worked or failed, with evidence: "we split the reviewer
  into a fresh-context agent and caught N% more bugs".
- Evals for coding agents: how someone measured an agent workflow, a new benchmark, results that
  question a benchmark.
- Context-management techniques: what to keep in CLAUDE.md, memory, retrieval vs long context.
- Anthropic Engineering posts.

Don't want:
- "10 Claude Code tips" listicles, prompt collections, "I built X in a weekend with AI" with no
  method.
- Opinion pieces on whether AI will replace programmers.
- Agent-framework launches with no users or evaluation.

## 2. Model releases and pricing (Anthropic first, others briefly)

Want:
- A new Claude model, a price change, rate-limit or context-window change, or a deprecation date.
- An API feature that changes what I can build (tool use, caching, batch, files, computer use).
- Other labs' releases (OpenAI, Google, open-weight models) only when they are a major release or
  a price move, as one line in "Worth a skim".

Don't want:
- Benchmark leaderboard churn, model rumours, funding rounds, executive moves.
- AI policy and safety news unless it changes what a developer can use or ship.

## 3. Browser extensions and store policy

Want:
- Chrome Web Store or Firefox Add-ons (AMO) policy changes, review-process changes, enforcement
  waves, Manifest V3 changes and deadlines.
- New extension APIs, especially side panel, offscreen documents, built-in AI APIs in Chrome.

Don't want:
- "Best extensions of 2026" lists; security-vendor reports about malicious extensions unless the
  store changed a policy because of them.

## 4. On-device and in-browser ML

Want:
- ONNX Runtime Web, WebGPU and WebAssembly inference: releases, benchmarks, how-tos.
- transformers.js releases; small vision models (detection, OCR, embeddings) that run in a
  browser or on a phone.
- Quantisation and model-size results that make a model practical client-side.

Don't want:
- Large-model training news; GPU and datacentre hardware.

## 5. Trading card game tooling and community-tool policy (Riftbound, One Piece TCG)

Want:
- Official announcements from Riot (Riftbound) or Bandai (One Piece TCG) about community tools,
  fan content, card data or API policy, and set releases that change card data.
- Notable community tools (deck builders, scanners, price trackers) and how they're received.

Don't want:
- Deck lists, tournament results, pack openings, price speculation.

## 6. Indie product, open source and small business (for a solo developer)

Want:
- A Show HN or launch post with real numbers (users, revenue, what worked).
- Open-source licensing or maintainer-funding changes that affect small projects.
- App-store, payment-provider or platform rule changes that hit solo developers.

Don't want:
- VC funding news, big-company earnings, growth-hacking advice.

## Tone and length

Morning Brew: plain, a little wry, no hype words ("game-changer", "revolutionary"). About 5
minutes. When unsure whether something matters to me, leave it out.
